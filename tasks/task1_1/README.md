# Task 1.1

1. Create a file `module.yaml` in the same directory as this README,
   containing the following line:

       product: jvm/app

2. Put your "Hello World" program in a file named `Main.kt`, in the
   `src` subdirectory.

3. Try compiling the program, with

       kotlin build

4. Try running the program, with

       kotlin run

If you encounter any problems, make sure that files are named correctly
and in the right place, and check that you have access to the Kotlin
Toolchain.
