# Task 2.4

1. Write a program in `src/Main.kt` that

   - Creates a `val` variable, assigning an integer to it
   - Prints the value of the variable
   - Attempts to assign a new value to the variable
   - Prints the value of the variable again

2. Attempt to compile the program with

       ./kotlin build

   Pay close attention to the error message that you see.

3. Fix the error by changing `var` to `var`. You should now be able to
   compile and run the program successfully.
