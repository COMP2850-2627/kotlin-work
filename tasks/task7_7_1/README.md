# Task 7.7.1

See the Programming Guide for full details of this task. The discussions
of file I/O and using extension functions on collections in the Guide cover
the majority of what you need to know to produce a solution.

Be sure to divide up your solution into three separate files:

- `main()` should go in `src/Main.kt`

- `readData()` should go in `src/Data.kt`

- The functions to compute a median and display statistics
  should go in `src/Stats.kt`
