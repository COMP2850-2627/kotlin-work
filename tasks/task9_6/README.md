# Task 9.6

Kotlin Toolchain project for an application that computes variance in a
numeric dataset.

See the Programming Guide for full details of this task.

## Linux & macOS

Run the unit tests for `variance()` with

    ./kotlin test

Run the application on a data file named `test.data` with

    ./kotlin run test.data

## Windows

On Windows, use `.\kotlin.bat` instead of `./kotlin`.
