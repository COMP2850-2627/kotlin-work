# Task 14.1

This task explores the implications of organizing code using packages.

1. Study the existing code, then check that it compiles.

2. Locate the JAR file containing the application bytecode, under
   `build/tasks/_task14_1_jarJvm`. Use the `jar` tool to examine its
   contents:

       jar -tf task14_1-jvm.jar

   Note the file paths for the two `.class` files created by the compiler.

3. Edit `Customer.kt` and add a package declaration, so that `Customer`
   is now part of the `myapp.orders` package. Verify that this results in
   a compiler error, because `Customer` and `main()` no longer belong to
   the same package.

4. Try fixing the problem by using the FQN of `Customer`, and by using an
   import statement instead of the FQN. Verify that both approaches fix
   the compiler error.

5. Use `jar` to examine the contents of the JAR file generated by the
   compiler. Note the change in file paths for the bytecode files.

6. Move `Customer.kt` so that it is in the directory `src/myapp/orders`.
   Leave `Main.kt` in `src`. Verify that the application still compiles
   successfully.
