# Task 1.3.2

This is an (almost) empty directory, within which you can create a Kotlin
Toolchain project from scratch using

    kotlin init

Select 'JVM Console Application' from the list of options and press Enter.

You can then run the project with

    ./kotlin run

or run its unit tests with

    ./kotlin test

(On Windows systems, use `.\kotlin.bat` instead of `./kotlin`.)
