# Task 5.2.1

Edit `src/Circle.kt`. Copy the `circleArea()` implementation from Section 5.2
of the Programming Guide into this file.

Then write a similar function to compute the perimeter of a circle, giving
it an expression body just like `circleArea()`.

After that, edit `src/Main.kt` and add a `main()` function that reads a value
for circle radius from command line arguments and then uses the functions from
`Circle.kt` to compute area and perimeter.

Your program should display the specified circle's area and perimeter with
four decimal places of accuracy.
