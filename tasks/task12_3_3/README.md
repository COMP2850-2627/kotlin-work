# Task 12.3.3

**NOTE: you need to have completed Task 12.3.2 before starting this task!**

1. Copy `Person.kt` and `Main.kt` from the `task12_3_2/src` subdirectory
   of your repository into `task12_3_3/src`.

2. Edit `Main.kt` and modify `main()` so that it attempts to create a `Person`
   with a zero-length name, or a name consisting only of spaces.

   Compile run and run the program to verify that these attempts succeed.

3. Modify the class so that it has the initializer block described in the
   Programming Guide. Recompile the program and try running it again to
   verify that invalid names now trigger an exception.
