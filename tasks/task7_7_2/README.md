# Task 7.7.2

See the Programming Guide for full details of this task.

The functions to load and save the database should be implemented in
`Database.kt`. The main program should be implemented in `Main.kt`. Both
files should be put in the `src/main/kotlin` subdirectory.

Create a file named `phone.csv` to hold the names and phone numbers. This
should go in the top-level diretory of the project, alongside this README.
There should be one pairing of name with phone number per line of the file,
with a comma separating the two strings.

Run the program with

    ./gradlew run
