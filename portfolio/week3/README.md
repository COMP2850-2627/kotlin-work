# Portfolio: Week 3

## Relevant Preparation

This work draws upon Sections 6 to 9 of the [Kotlin Programming Guide][guide],
and on your solution to a Week 2 portfolio task.

Subsections [6.5][sec65], [7.3][sec73], [7.6][sec76] and [9.3][sec93] are of
particular relevance, as are any programming tasks in those subsections.

Part of this work involves adapting your solution to [Task 7.7.1][task], so
make sure you have completed that before you begin.

## Instructions

There are *two* separate parts to this assignment - see the README files in
subdirectories `triangles` and `median` for full details.

In each part, you will be working with small Kotlin functions. In the first
part of the assignment, a full set of tests is provided for you to verify the
correctness of your work; in the second part, you will need to write most of
the tests yourself.

You can run the tests for both parts with

    ./kotlin test

Note that this will only work once you have compiling implementations of
the relevant functions.

To achieve a pass on this assignment, **there must be no failing tests**.
You will also need to provide an acceptable written justification for the
tests you have written yourself, and the code you submit must have an
acceptable style.

The minimum standard for an acceptable submission is **5 passing tests**.

## Submission

Run the command

    ./kotlin clean

Then create a Zip archive of your entire `week3` directory. **Check the Zip
archive contents to make sure that it contains all of your files.**

Access Gradescope via the link provided in Minerva. On Gradescope, answer
the first question by uploading the Zip archive that you have just created.
Then answer the second question by supplying a written explanation of your
tests for the `median()` function.
